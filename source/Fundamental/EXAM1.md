**Programming Fundamentals I - Exam 1 Study Plan**

This study plan is designed to help you review the concepts covered in Chapter 1-4 of your Programming Fundamentals I
course. It focuses on the types of questions asked in Exam 1.

**I. Core Python Syntax & Operators (High Priority)**

* **String Comparison:**
    * Understand how string comparison works (e.g., `'there' == 'here'`).
    * **Action:** Practice various string comparison scenarios. (Question 1)
* **Print Statement and `sep` argument:**
    * Know how to use the `print()` function with the `sep` argument to control output separators.
    * **Action:** Experiment with `print()` and different `sep` values. (Question 2)
* **Modulo Operator and Data Types:**
    * Understand the `%` (modulo) operator and how to determine the resulting value and data type (e.g., `int`, `float`,
      `bool`, `str`).
    * **Action:** Work through examples involving the modulo operator and identify data types. (Question 3)
* **Comparison Operators:**
    * Familiarize yourself with comparison operators like `<=`.
    * **Action:** Review all comparison operators (`==`, `!=`, `<`, `>`, `<=`, `>=`) and their boolean outputs. (
      Question 4)
* **Escape Sequences in Strings:**
    * Know how to use escape sequences, especially `\` for backslashes in paths and `\'` for single quotes within
      strings.
    * **Action:** Practice printing strings with various escape sequences. (Question 9, 15)
* **Augmented Assignment Operators:**
    * Understand what augmented assignment operators are and be able to identify them (e.g., `+=`, `-=`, `*=`, `/=`,
      `%=`).
    * **Action:** Review and differentiate between augmented assignment operators and other operators. (Question 12)
* **Accumulator Pattern:**
    * Understand the concept of an accumulator and how it's implemented in code (e.g., `total += number`).
    * **Action:** Practice writing code that uses an accumulator to sum numbers. (Question 13)
* **Mathematical Operators:**
    * Recall common mathematical operators, specifically the exponentiation operator (`**`).
    * **Action:** Review all standard mathematical operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`). (Question 17)
* **`print()` and `end` argument:**
    * Understand how to use the `end` argument in `print()` to control what character is printed at the end of the
      output, preventing a new line.
    * **Action:** Practice using the `end` argument to produce specific output formats. (Question 19)
* **Not-Equal-To Operator:**
    * Identify the not-equal-to operator (`!=`) in Python.
    * **Action:** Practice using the `!=` operator in conditional statements. (Question 27)
* **`input()` function:**
    * Know that the `input()` function is used to read user input from the keyboard.
    * **Action:** Practice writing programs that take user input. (Question 28)

**II. Control Flow Statements (High Priority)**

* **For Loops:**
    * **Basic `for` loop usage:** Write `for` loops to display sequences of numbers with specific patterns and use the
      `end` argument effectively.
    * **`range()` function:** Understand the three arguments of the `range()` function (`start`, `stop`, `step`) and
      predict the sequence of numbers it generates.
    * **Action:** Practice writing `for` loops for various number sequences. Trace the values of loop variables when
      using `range()`. (Question 5, 24, 29)
* **If-Else Statements:**
    * Write `if-else` statements to check conditions and execute different blocks of code.
    * **Logical Operators:** Understand how to use `or` to check if a variable is outside a given range.
    * **Action:** Practice writing `if-else` statements with different conditions and logical operators. (Question 6)
* **While Loops:**
    * Write `while` loops that continue based on user input or a specific condition.
    * **Input in loops:** Integrate `input()` within `while` loops to control loop termination.
    * **Accumulators in loops:** Use accumulators inside loops to calculate sums or totals.
    * **Action:** Practice writing `while` loops for interactive programs, including user prompts for continuation. (
      Question 7, 10)
* **Loop Structures (General Concepts):**
    * Understand the purpose of repetition (looping) structures.
    * Differentiate between different types of loops (e.g., condition-controlled, count-controlled).
    * **Action:** Review the definitions and characteristics of various loop types. (Question 22, 30)
* **Priming Read:**
    * Understand the concept and purpose of a "priming read" in a validation loop.
    * **Action:** Review how priming reads are used to get the initial input before a loop starts. (Question 20)
* **Decision Structures:**
    * Know the terminology for decision structures with two possible execution paths (e.g., dual alternative).
    * **Action:** Understand the different types of decision structures (single alternative, dual alternative). (
      Question 21)
* **Tracing Loop Execution:**
    * Be able to trace the execution of a `for` loop and predict the final output, especially when an accumulator is
      involved.
    * **Action:** Manually trace code snippets with loops and accumulators to predict the final value of variables. (
      Question 32)

**III. Fundamental Computer Concepts & Terminology (Medium Priority)**

* **Solid State Drives (SSDs):**
    * Understand the basic characteristics of an SSD (no moving parts, faster than traditional hard drives).
    * **Action:** Review the advantages of SSDs over HDDs. (Question 8)
* **Number Encoding (Two's Complement):**
    * Recall the encoding technique used for negative numbers in computer memory.
    * **Action:** Understand that two's complement is used for representing negative numbers. (Question 14)
* **Computer System Components:**
    * Identify the major components of a typical computer system (CPU, main memory, secondary storage devices).
    * **Action:** Be able to distinguish between hardware components and software components (like an operating
      system). (Question 18)
* **Input Validation:**
    * Define input validation and its purpose in programming.
    * **Action:** Understand why input validation is crucial for robust programs. (Question 23)
* **Pseudocode:**
    * Understand what pseudocode is and its purpose in program design.
    * **Action:** Review the definition of pseudocode as an informal planning language. (Question 25)
* **Machine Language:**
    * Recognize an example of machine language instructions (binary code).
    * **Action:** Understand that machine language is the lowest-level programming language directly understood by the
      CPU. (Question 26)
* **First Programmable Electronic Computer:**
    * Know which computer is considered the world's first programmable electronic computer.
    * **Action:** Remember that ENIAC holds this distinction. (Question 31)

**IV. General Study Tips**

* **Review Course Materials:** Go back through your textbook chapters (1-4), lecture notes, and any programming examples
  provided by your instructor.
* **Practice Coding:** The best way to learn programming is by doing. Re-write the example correct responses from the
  exam questions without looking at the answers first.
* **Trace Code Manually:** For questions involving loops and variable changes, manually trace the execution of the code
  line by line to understand how the values change.
* **Understand Concepts, Not Just Memorize:** Focus on *why* a particular answer is correct, not just *what* the correct
  answer is.
* **Utilize Online Resources:** If you're struggling with a concept, search for tutorials or explanations online (e.g.,
  Python `for` loops, `while` loops, data types).
* **Form a Study Group:** Discussing questions and concepts with peers can help solidify your understanding.
* **Self-Assess:** Try to explain concepts and code snippets in your own words. If you can't explain it clearly, you
  likely don't fully understand it.
